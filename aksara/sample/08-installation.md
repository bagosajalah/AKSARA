# Nawasara Agent — Instalasi & Konfigurasi

## Install Satu Baris

```bash
curl -sSL https://nawasara.ponorogo.go.id/agent/install.sh | bash
```

Script akan:
1. Deteksi OS dan arsitektur
2. Download binary yang sesuai
3. Verifikasi checksum SHA256
4. Tanya API key (atau baca dari env)
5. Buat `/etc/nawasara-agent/config.yaml`
6. Register agent ke Dashboard
7. Install sebagai systemd service
8. Mulai agent

---

## Install dengan API Key Langsung (non-interactive)

```bash
NAWASARA_API_KEY=nwa_xxxxxxxxxxxx \
NAWASARA_URL=https://nawasara.ponorogo.go.id \
NAWASARA_AGENT_NAME=web-dinkes-01 \
curl -sSL https://nawasara.ponorogo.go.id/agent/install.sh | bash
```

Cocok untuk provisioning otomatis / Ansible / cloud-init.

## Konfigurasi

File: `/etc/nawasara-agent/config.yaml`

```yaml
# Nawasara Agent Configuration
# Generated by install script — edit sesuai kebutuhan

# === Koneksi Dashboard ===
api_key: nwa_xxxxxxxxxxxx
dashboard_url: https://nawasara.ponorogo.go.id
agent_name: web-diskominfo-01       # nama tampil di Dashboard
agent_id: agt_01j2k3l4m5           # di-set otomatis saat register

# === Collector ===
collector:
  web_server: auto                  # auto | nginx | apache
  log_paths:
    nginx:
      access: /var/log/nginx/access.log
      error: /var/log/nginx/error.log
      # glob untuk virtual hosts:
      vhosts: /var/log/nginx/*_access.log
    apache:
      access: /var/log/apache2/access.log
      error: /var/log/apache2/error.log
  ssh_log: auto                     # auto detect auth.log vs secure
  metrics_interval: 30s             # interval ambil CPU/RAM/Disk

# === Analyzer ===
analyzer:
  rules_dir: /etc/nawasara-agent/rules/
  rules_sync_interval: 6h
  correlation_window: 5m
  default_threshold: 20

# === Reporter ===
reporter:
  push_timeout: 10s
  retry_interval: 30s
  buffer_db: /var/lib/nawasara-agent/buffer.db
  buffer_max_age: 168h              # 7 hari
  buffer_max_size_mb: 100
  heartbeat_interval: 60s

# === Executor (Phase 2+) ===
executor:
  enabled: false                    # aktifkan manual setelah Phase 2
  poll_interval: 30s
  allowed_actions:                  # whitelist — jangan hapus!
    - block_ip
    - unblock_ip
    - restart_nginx
    - restart_apache
    - restart_php_fpm
    - artisan_queue_restart
    - artisan_cache_clear

# === Plugins ===
plugins:
  dir: /etc/nawasara-agent/plugins/available/
  enabled:
    - nginx
    - ssl
  # docker, laravel, cron, php-fpm, mysql — install via CLI
```

## Auto-Update

### Mekanisme

```bash
# Agent cek versi setiap 6 jam
# GET /api/agent/version
# Response: { "latest": "1.2.0", "current": "1.1.0", "changelog_url": "..." }

# Jika ada versi baru:
1. Download binary baru ke /tmp/nawasara-agent-new
2. Verify SHA256 + GPG signature
3. chmod +x
4. mv /usr/local/bin/nawasara-agent /usr/local/bin/nawasara-agent.bak
5. mv /tmp/nawasara-agent-new /usr/local/bin/nawasara-agent
6. systemctl restart nawasara-agent
7. Kirim konfirmasi versi baru ke Dashboard
```

### Rollback Otomatis

Jika agent tidak bisa start setelah update (tidak ada heartbeat dalam 2 menit):
```bash
# watchdog di systemd ExecStartPre
mv /usr/local/bin/nawasara-agent.bak /usr/local/bin/nawasara-agent
systemctl restart nawasara-agent
```

### Control dari Dashboard
Admin bisa:
- Enable/disable auto-update per agent
- Set versi minimum yang wajib (force update)
- Trigger update manual ke agent tertentu

## Systemd Service

`/etc/systemd/system/nawasara-agent.service`

```ini
[Unit]
Description=Nawasara Security Agent
After=network.target
Wants=network-online.target

[Service]
Type=simple
User=root
ExecStart=/usr/local/bin/nawasara-agent run --config /etc/nawasara-agent/config.yaml
Restart=always
RestartSec=5s
LimitNOFILE=65536

# Resource limits — agent harus ringan
CPUQuota=10%
MemoryMax=128M

[Install]
WantedBy=multi-user.target
```

## CLI Commands

```bash
# Status agent
nawasara-agent status

# Test koneksi ke Dashboard
nawasara-agent ping

# Jalankan manual (foreground, untuk debug)
nawasara-agent run --debug

# Plugin management
nawasara-agent plugin list
nawasara-agent plugin install docker
nawasara-agent plugin enable docker
nawasara-agent plugin disable docker
nawasara-agent plugin remove docker
nawasara-agent plugin status

# Rule management
nawasara-agent rules sync          # sync rules dari Dashboard sekarang
nawasara-agent rules list          # tampilkan semua rules aktif
nawasara-agent rules test {file}   # test rule terhadap log file

# Info
nawasara-agent version
nawasara-agent info                # tampilkan config, OS, plugin aktif

# Uninstall
nawasara-agent uninstall
```

## Uninstall

```bash
nawasara-agent uninstall

# Atau manual:
systemctl stop nawasara-agent
systemctl disable nawasara-agent
rm /etc/systemd/system/nawasara-agent.service
rm /usr/local/bin/nawasara-agent
rm -rf /etc/nawasara-agent/
rm -rf /var/lib/nawasara-agent/
systemctl daemon-reload
```

Data di Dashboard tidak dihapus otomatis — admin hapus dari Dashboard jika perlu.
